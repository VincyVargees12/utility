How it works

Every box shown here represents the same content in a different format. Type into the "Text (ASCII / ANSI)" box and click its Convert button to fill in every other format. You can also edit any other box directly — clicking its own Convert button treats that box as the source and updates the rest, including Text, from it.

Features

  • ✓ Binary, Hex, Decimal (space-separated byte values)
  • ✓ Base64 with full Unicode/UTF-8 support
  • ✓ ROT13 letter substitution cipher
  • ✓ URL (percent) encoding, form style with +
  • ✓ HTML entity encoding, including non-ASCII
  • ✓ Any box can be the source — fully two-way
  • ✓ "Highlight Text" selects a box's full content
  • ✓ Copy any box straight to your clipboard
  • ✓ Runs entirely client-side — nothing is uploaded
