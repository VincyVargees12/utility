What is UUID?

UUID (Universally Unique Identifier) or GUID (Globally Unique Identifier) is a 128-bit number used to uniquely identify information. UUIDs are used in databases, distributed systems, and APIs.

UUID Versions

  • v1: Time-based with MAC address
  • v4: Random (most common)

Common Use Cases

  • • Database primary keys
  • • Session identifiers
  • • File naming
  • • API request tracking
  • • Distributed system IDs

What does decoding show?

Every UUID reserves a few bits to encode its version and variant, regardless of how it was generated. For version 1, the remaining bits are a real timestamp, clock sequence, and node ID that this tool reconstructs. Versions 3 and 5 embed a one-way hash, so their source data can't be recovered — only the version and variant are meaningful. Version 4 is pure randomness with nothing else to extract.

Variant Reference

  • RFC 4122: The standard variant almost all UUIDs use
  • NCS: Legacy, reserved for backward compatibility
  • Microsoft: Legacy COM/OLE GUIDs
  • Future: Reserved, not yet defined
